# Lumen Web

Frontend do leitor, construído com Next.js, Tailwind CSS 4 e componentes no padrão shadcn/ui.

## Desenvolvimento

1. Copie `.env.local.example` para `.env.local`.
2. Execute `npm install`.
3. Execute `npm run dev`.

Abra `http://localhost:3000`.

O backend precisa estar em `http://localhost:3001/api`. Para o login Google, mantenha `FRONTEND_URL="http://localhost:3000"` no `.env` do backend.
